## Assignment Guidance

Each document restarts scenario lettering from **A** and uses a dedicated scenario ID prefix:

- `TT-SETUP-*` for setup QA
- `TT-WORKSPACE-*` for workspace and review QA
- `TT-UPLOAD-*` for upload view QA
- `TT-SUB-*` for substitution and edge-case recreation QA

Use this index only for navigation. Testers should execute from the specific split document assigned to them.
